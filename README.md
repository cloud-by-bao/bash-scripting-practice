# Bash Scripting Practice (30-Day Challenge)

## 📌 Overview
This repository documents my **30-day journey practicing Bash scripting** for Cloud & DevOps.  
The purpose is to strengthen my **Linux fundamentals, automation mindset, and scripting skills**, which are essential for real-world DevOps and cloud engineering.

Each day includes:
- A Bash script (`.sh`)
- A dedicated `README.md` explaining what the script does
- Example outputs
- A short note on **real-world DevOps/Cloud relevance**

---

## 📅 Week 1: Bash Fundamentals
- [Day 1: File & Directory Automation](week1/day1/README.md)  
  *Create directories, generate timestamped log files, and move them to backups (simulating log rotation & archiving).*

- [Day 2: System Info Script](week1/day2/README.md)  
  *Print OS, disk usage, memory usage, and uptime (simulating system health checks).*

- [Day 3: Log Rotation](week1/day3/README.md)  
  *Archive old logs and clear them from active use (simulating production log rotation).*

- [Day 4: Top 10 Largest Files](week1/day4/README.md)  
  *Find and sort the largest files (useful for disk space monitoring).*

- [Day 5: Network Health Check](week1/day5/README.md)  
  *Ping multiple servers and show whether they are UP or DOWN.*

- [Day 6: Log Parser](week1/day6/README.md)  
  *Extract error codes (like 404s) and unique IPs from web server logs.*

- [Day 7: Admin Toolkit](week1/day7/README.md)  
  *A menu-driven script combining features from Days 1–6 (mini sysadmin toolkit).*
